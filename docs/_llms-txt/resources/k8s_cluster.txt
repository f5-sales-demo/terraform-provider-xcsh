# xcsh_k8s_cluster

Category: Kubernetes
K8s_cluster will create the object in the storage backend for namespace metadata.namespace

## Required

- name
- namespace

## Server Defaults (safe to omit)

- cluster_scoped_access_deny
- no_cluster_wide_apps
- no_global_access
- no_insecure_registries
- no_local_access
- use_default_cluster_role_bindings
- use_default_cluster_roles
- use_default_psp
- vk8s_namespace_access_deny

## Minimal Valid Config

```terraform
resource "xcsh_k8s_cluster" "example" {
  name      = "example-k8s-cluster"
  namespace = "system"
}
```

## Dependencies

Requires: none
