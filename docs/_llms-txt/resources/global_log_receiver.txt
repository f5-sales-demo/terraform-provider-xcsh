# xcsh_global_log_receiver

Category: Monitoring
New Global Log Receiver object

## Required

- name
- namespace
- log_type
- receiver_choice

## Server Defaults (safe to omit)

- ns_current
- request_logs.sampled

## Minimal Valid Config

```terraform
resource "xcsh_global_log_receiver" "example" {
  name      = "example-global-log-receiver"
  namespace = "staging"
}
```

## Dependencies

Requires: none
