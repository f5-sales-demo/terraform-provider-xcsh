# xcsh_voltstack_site

Category: Sites
Deploying App Stack edge computing sites

- name
- namespace
- address
- volterra_certified_hw

```terraform
  namespace = "staging"

  volterra_certified_hw = "example-value"
  worker_nodes          = ["example-value"]
  address               = "example-value"
}
```
