# xcsh_azure_vnet_site

Category: Sites
Deploying F5 sites within Azure Virtual Network environments

## Required

- name
- machine_type
- resource_group
- ssh_key

## Server Defaults (safe to omit)

- block_all_services
- disk_size
- ingress_gw.accelerated_networking
- ingress_gw.performance_enhancement_mode
- logs_streaming_disabled
- machine_type
- no_worker_nodes
- tags

## Minimal Valid Config

```terraform
resource "xcsh_azure_vnet_site" "example" {
  name      = "example-azure-vnet-site"
  namespace = "system"

  machine_type   = "example-value"
  resource_group = "example-value"
  ssh_key        = "example-value"
}
```

## Dependencies

Requires: none
