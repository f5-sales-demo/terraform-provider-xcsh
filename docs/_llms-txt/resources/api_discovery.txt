# xcsh_api_discovery

Category: API Security
API discovery creates a new object in the storage backend for metadata.namespace

## Required

- name
- namespace
- user_defined_api_discovery_policy

## Server Defaults (safe to omit)

- custom_auth_types
- user_defined_api_discovery_policy.discovery_rules
- user_defined_api_discovery_policy.inclusive

## Minimal Valid Config

```terraform
resource "xcsh_api_discovery" "example" {
  name      = "example-api-discovery"
  namespace = "staging"
}
```

## Dependencies

Requires: none
