### content_type property

Type: `"string"`. Computed, Sensitive.

The HTTP Content-Type header value specifying the content type of the body.

<a id="schema-data"></a>

### data property

Type: `"string"`. Computed, Sensitive.

The HTTP request/response body as raw binary.
