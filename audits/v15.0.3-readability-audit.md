# Terraform documentation readability audit: published v15.0.3

The exact v15.0.3 tree is the baseline. The scanner read 16,366 canonical and 1,426 Registry Markdown files. Every finding includes a source path, published route, line, severity, and detail digest in `v15.0.3-readability-findings.jsonl.gz` (deterministic gzip, JSON Lines).

Reproduce from this source branch:

```sh
python3 tools/audit-doc-readability.py --git-ref v15.0.3 --redact-detail \
  --ledger /tmp/readability.jsonl --summary /tmp/readability.json
```
